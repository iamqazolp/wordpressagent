This project's goal is to create an app for a single user. That user manages multiple websites using WooCommerce and his job is to make posts about products.
The features that he wants:
1. Given a product's name, find a few posts about it on the internet and use them as material to write a post that only keeps essential information about the product without the promotional material of sites we got the referenced posts from. The agent should also compare and fact-check the information
2. Given a list of images, the agents should automatically add the images to the posts.
3. The layout of the new posts must be similar to older posts
4. Automatically post new posts. The user only provides the inputs (product name, images). 
5. Image processing: removes background, logo (this is for the future)
